# sysadmin-toolkit

Два набора Python-утилит для повседневных задач техподдержки/sysadmin:
перенос старых bash-скриптов на Python и набор с нуля написанных
диагностических инструментов для доменов и серверов.

Только стандартная библиотека и минимум внешних зависимостей (`dnspython`,
`requests`, опционально `python-whois`). Никаких внутренних систем,
кредов или реальных клиентских данных — все скрипты работают с публичными
протоколами (DNS, TLS handshake, HTTP) или с локальной файловой системой.

## Состав

### [bash-to-python-scripts/](bash-to-python-scripts/)

15 личных bash-скриптов (macOS-утилиты, git-автоматизация, C-проекты
school21), переписанных на Python — с сохранением исходной логики и
явным описанием, зачем каждый скрипт был нужен изначально. Реальные пути и
URL из оригиналов заменены на CLI-аргументы.

### [support-diagnostics-scripts/](support-diagnostics-scripts/)

5 CLI-утилит для диагностики доменов/серверов, характерных для техподдержки
хостинга: проверка SSL-сертификата, DNS-записей, открытых портов,
HTTP-доступности и объединяющий отчёт по домену целиком.

## Почему так

Показывает практический навык, который не всегда виден в бэкенд-портфолио:
превращение рабочих bash-заготовок в читаемые, документированные,
CLI-совместимые Python-инструменты — и написание диагностических утилит,
которые реально нужны в поддержке хостинга (не учебные примеры).

Подробности, аргументы командной строки и примеры запуска — в README
каждой из двух папок.
